# Бухгалтер — демо-версія

Демо сайту «Бухгалтер» для портфоліо: клієнт відкриває посилання й бачить повноцінний сайт із готовими даними.
Може додавати операції, міняти план, цілі, категорії, тему — усе як у справжній версії.

- **Готові суми:** при першому відкритті генеруються операції за останні 12 місяців + поточний, план на кожен місяць і 4 цілі в різних валютах. Дати рахуються від сьогодні, тож демо не «старіє».
- **Зміни не зберігаються:** дані живуть лише у вкладці (sessionStorage). Оновив сторінку — зміни на місці; закрив вкладку — наступного разу знову чисте демо. Кнопка «Почати заново» в банері скидає одразу.
- **Без сервера й акаунтів:** нічого нікуди не надсилається. Єдиний запит — курс НБУ через `/api/rates`.

## Що всередині

```
public/index.html          сторінка — ТОЧНА копія з основного репо hryvnevyi-balans
public/db.js               демо-сховище замість хмари + банер «Демо-версія»
public/icon.svg, manifest  іконка
api/rates.js               курс НБУ (та сама копія, що в основному репо)
vercel.json                налаштування Vercel
```

## Деплой

1. Створіть репозиторій (наприклад `ssanqk/buhgalter-demo`) і завантажте туди вміст цієї папки.
2. vercel.com → **Add New → Project** → оберіть цей репозиторій → **Deploy**. Жодних змінних і бази не потрібно.
3. Отримане посилання ставте на лендінг.

## Оновити демо після змін в основному сайті

Скопіюйте `public/index.html` з основного репо поверх цього — і все. `db.js` не чіпайте: він підміняє лише сховище.

## Налаштування (вгорі `public/db.js`)

- `PORTFOLIO_URL` — посилання на портфоліо; якщо вписати, у банері з'явиться кнопка «← До портфоліо».
- `MONTHS_BACK` — скільки місяців історії заповнювати.
- Суми, назви операцій і цілі — у функції `buildSeed()`.
- Якщо змінили демо-дані, збільште версію в `STORE` (`hb-demo:v2`), щоб у вже відкритих вкладках вони перегенерувались.
